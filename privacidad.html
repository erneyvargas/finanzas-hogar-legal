Política de privacidad

Última actualización: 29 de septiembre de 2026

Finanzas Hogar es una aplicación de uso personal y familiar. Esta política explica qué datos usa, para qué y cómo se protegen.

Datos de la cuenta de la aplicación

Para iniciar sesión se guarda el correo electrónico del usuario y la información financiera que él mismo registra (cuentas, movimientos, presupuestos y facturas). Estos datos se almacenan en Supabase y solo los ven los miembros del mismo hogar.

Datos de Gmail

La conexión con Gmail es opcional y la activa cada persona desde la aplicación. Se solicita únicamente el permiso de solo lectura https://www.googleapis.com/auth/gmail.readonly.

  • Qué se lee: los mensajes nuevos que traen un archivo .zip adjunto. De ellos solo se conservan las facturas electrónicas de la DIAN (XML UBL y su PDF).
  • Qué se guarda: de cada factura, el proveedor, su NIT, el CUFE, la fecha, los totales, los impuestos y los ítems, junto con el identificador del mensaje para no procesarlo dos veces. El XML y el PDF se guardan en un almacenamiento privado del hogar. También se guardan la dirección de Gmail conectada y un token de acceso, que solo usa el servidor y ningún usuario puede leer.
  • Qué no se hace: no se guarda el cuerpo de los correos, no se leen otros adjuntos ni otros mensajes, no se envía ningún correo y no se modifica el buzón.
  • Para qué se usa: solo para mostrar las facturas al usuario en la bandeja "Facturas por revisar" de la aplicación.

Uso limitado de los datos de Google

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google cumplen la Política de datos del usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. En concreto, los datos de Gmail:

  • no se venden ni se comparten con terceros;
  • no se usan para publicidad;
  • no se usan para entrenar modelos de inteligencia artificial ni se envían a servicios de inteligencia artificial;
  • no los lee ninguna persona, salvo el propio usuario o con su consentimiento expreso para resolver un problema, o cuando la ley lo exija.

Proveedores

Los datos se almacenan y procesan en Supabase (base de datos, almacenamiento y funciones del servidor) y las notificaciones de correo nuevo llegan a través de Google Cloud Pub/Sub. No hay otros destinatarios.

Cómo desconectar Gmail y borrar los datos

En la aplicación, la opción de desconectar Gmail detiene la lectura, revoca el permiso y borra el token guardado. El permiso también se puede retirar en cualquier momento desde myaccount.google.com/permissions. Para borrar las facturas ya importadas o la cuenta completa, basta con escribir al correo de contacto.
